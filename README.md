# Cyberpunk RED: Edgerunners Quickhacks

A Foundry VTT module for Cyberpunk RED that adds the Quickhack system from the Cyberpunk: Edgerunners Mission Kit.

## Features

### Quickhacks

Adds 11 Quickhack Programs:

- Impair Movement
- Sonic Shock
- Overheat
- Short Circuit
- Cyberware Malfunction
- Lure
- Slow
- Synapse Burnout
- Puppet
- Shard Ejection
- System Reset

### New NET Actions

- Breach
- Perform Quickhack

### Cyberware

- Self-ICE

### Drugs

- Immunoblockers

### Reference Journal

- Quickhack Rules Reference

### Automation

Current automation includes:

- Neuroport Breach workflow
- Interface Rank 3 auto-bypass support
- Self-ICE Passwall detection
- Breach chat cards
- Quickhack execution dialog
- Installed Cyberdeck Quickhack filtering
- Quickhack status effect application
- Quickhack duration tracking
- MOVE reduction automation
- Synapse Burnout damage automation
- Overheat state tracking
- Cyberware disabling support
- Direct Connection tracking
- Neuroport breach tracking

#### Breach System

- Neuroport Firewall support
- Self-ICE support
- Interface Rank 3 auto-bypass handling
- Dedicated Breach roll card
- Critical Success and Critical Failure support
- GM and Player compatible workflows

## Installation

Manifest URL: https://raw.githubusercontent.com/Adevion/cyberpunk-red-quickhacks/main/module.json

### Quick Start

1. Install a Quickhack Program into a Cyberdeck.
2. Target a valid token.
3. Use Breach to gain access.
4. Execute Quickhacks against Breached targets.
5. Self-ICE increases target security and requires additional Breach checks.

## Current Known Limitations

Some Quickhacks still require GM adjudication for roleplay, movement, or narrative outcomes.
The following systems are partially automated and may still require GM interaction:

- Puppet
- Lure
- Short Circuit
- Cyberware Malfunction
- Shard Ejection
